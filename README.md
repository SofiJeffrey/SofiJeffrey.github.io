# Sofi Jeffrey — personal website

A static portfolio focused on food and beverage R&D, process modeling, chemical engineering, and mathematics. Served by GitHub Pages at `sofijeffrey.com` using the existing `CNAME`.

## Preview

No package installation or build step is needed. Open `index.html` in a browser, or run a local static server in this folder (for example, `python -m http.server 8000`) and visit `http://localhost:8000`.

## Update content

- `index.html`: experience, project summaries, publications, education, contact links, and search/social metadata.
- `assets/css/portfolio.css`: responsive layout, colors, typography, keyboard focus, and print styles.
- `pdf/Sofi-Jeffrey-Resume.pdf`: downloadable resume; replace this file when the resume changes.
- `images/img3.jpg`: existing laboratory portrait.
- `assets/favicon.svg`: site icon.
- `robots.txt` and `sitemap.xml`: search discovery.

The current site works without JavaScript, external fonts, or a build pipeline. Older template assets remain in place but are not loaded. `README.txt` and `LICENSE.txt` retain the original HTML5 UP template attribution and licensing information.

The 2025 journal publication links to its verified publisher record through DOI `10.1007/s00283-024-10402-w`. The local `Kunz Paper.pdf` is a distinct 2024 course paper. Existing unlinked resources remain available at their original paths.

The fermentation workflow graphic is conceptual, not a plot of experimental results. Employer case summaries include only high-level resume information and do not imply achieved savings, process improvements, or validated predictions.
